These are recorded HandLandmarker test outputs from Google's MediaPipe repository (Apache-2.0), with source URLs retained in each JSON. The source classifications are anatomical Right. Tests reflect the world x axis and image x coordinate to cover the corresponding left hand, and rotate the world landmarks to exercise palm orientation.

They verify detector-result ingestion, handedness, individual native finger joints and network relay. They are not a recording of the user's webcam and are not proof of live camera performance.
